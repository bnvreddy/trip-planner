# Frontend

React 19 + Vite + Tailwind + Leaflet UI for the trip planner.

Setup, architecture and the scheduling rules live in the [root README](../README.md).

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
npx eslint src
```

The API base defaults to `http://127.0.0.1:8000`; override it with `VITE_API_BASE`.
